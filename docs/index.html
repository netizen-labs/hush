// why hush

Small enough to read. Serious enough to trust.

📦

Zero dependencies

Pure standard-library Python — a few hundred readable lines. No C extensions, no transitive tree, no supply chain to trust.

🎯

Two detectors

Curated regex rules for known secret shapes, plus a Shannon-entropy detector for the random blobs no pattern knows. Deduplicated, never doubled.

🌿

Git-native

Gate the index with --staged before every commit, or sweep the whole history for secrets that were "removed" but still live in old commits.

📋

Reviewable baselines

Accept known findings into a baseline that stores fingerprints and redacted context — never a raw secret. Only new leaks get reported.

🙈

Safe by default

Secrets are redacted in every report unless you explicitly reveal them. Nothing leaks through the tool built to stop leaks.

⚙️

CI-ready

Clean exit codes (0/1/2), JSON output, a pre-commit hook and a GitHub Actions workflow. Drops into any pipeline in minutes.

// get started

Three commands to a safer repo

# install & scan
pip install hush-scan
hush scan

# gate every commit (git index)
hush scan --staged

# audit history for old leaks
hush scan --history
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/netizen-labs/hush
    rev: v0.1.0
    hooks:
      - id: hush
